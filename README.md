# Hostel-complaint-management-System
A web-based Hostel Complaint Management System using Python, Flask, HTML, CSS and SQLite.
## Project Overview
The Hostel Complaint Management System is a web-based application that helps students submit hostel complaints and allows the warden to view complaints and update their status.

## Features
- Student complaint submission
- Stores complaint details using SQLite
- Warden dashboard to view submitted complaints
- Displays complaint status
- Mark complaints as completed

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Project Structure
- `app.py` — Flask application and backend logic
- `templates/index.html` — Student complaint form
- `templates/warden.html` — Warden dashboard
- `static/style.css` — Website styling

## How to Run
1. Install Python.
2. Install Flask using `python -m pip install flask`.
3. Open the project folder in VS Code.
4. Run `python app.py` using your installed Python interpreter.
5. Open `http://127.0.0.1:5000` in a browser.
6. Open `http://127.0.0.1:5000/warden` to view the warden dashboard.
